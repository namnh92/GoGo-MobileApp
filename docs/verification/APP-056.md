# APP-056 — latest three GoGo reviews on Place Detail

Refs #212. Requires GoGo-BE#570 (PR #587, OpenAPI alpha.32, `GET /places/{id}/reviews`).

Place Detail shows a "latest GoGo reviews" section under the rating cards. It reads its own query, so loading shows a skeleton and a failure shows an inline message with retry while the place facts stay usable. With no published review it says so in words. Each row shows author, written date, rating as text and the review text; a deleted account renders a "deleted user" label. The Google rating card and the GoGo card are unchanged: reviews never feed a number into either, and the section carries a GoGo attribution line. The server lists only moderated reviews; the query refetches after 30 seconds and its key is excluded from offline persistence, so a review a moderator hid does not return from disk.

Validation: `api:check`, `tsc --noEmit` and `expo lint` pass; vitest 282 tests pass (39 skipped), including the new persistence case; full `jest --ci` 29 suites / 169 tests pass and the process exited on its own (exit 0) without `--forceExit`. New place reviews spec covers zero, one and three reviews, deleted author, separation from the Google rating, loading, error with retry, cached data after a failed refetch, and a review disappearing after moderation. The place-detail sheet spec (#222) still passes; the map (#220) is untouched.
