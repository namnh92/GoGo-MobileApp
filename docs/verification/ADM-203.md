# ADM-203 — account administrative area

Refs #208. Stacked on #229 (ADM-201). Requires the BE ADM-019 contract and migration before rollout.

Account defaults now use the shared province–commune picker. Save sends canonical codes and datasetVersion; display labels come from the server. Whole-province scope and clearing are supported. Existing legacy labels remain visible until explicitly replaced or cleared. Changing unrelated defaults does not rewrite an area. A changed dataset requires reselection.

Validation: typecheck, lint and generated API check pass. All 18 account-defaults, avatar and administrative-picker UI tests pass. This verifies selection payloads, legacy display, clearing, errors and avatar regression. No native dependencies added. DEV and device acceptance remain pending.

Rollback: revert this consumer before its shared picker foundation; the backend additive field may remain deployed.
