# ADM-204 — Home looks where the user is, then the account area

Refs #209. Consumes GoGo-BE#583 (ADM-021, OpenAPI 1.0.0-alpha.32; the vendored `openapi/gogo.v1.yaml` is byte-identical to that PR's head).

## Behaviour

Home's suggestion rail is scoped in this order:

1. **A fresh device position.** Read without prompting: only when permission is already granted, from a last-known fix at most 10 minutes old, or a new fix within 8 seconds. An older or slower fix counts as no position.
2. **The account's canonical area** (ADM-203), only when its status is `current`.
3. **None.** Home says the suggestions are general, explains a replaced account area, and offers "Dùng vị trí hiện tại" (permission asked on that tap) and "Chọn khu vực" (account information, or sign-in for a guest).

The two are never combined in a request. Search waits until the scope is known, so one scope produces one request. The label under the section title comes from the server's `meta.location` — a server that does not report a scope gets no label rather than a claim.

Returning to the app re-checks the position at most once a minute; a tap on "use location" re-checks immediately. An account switch changes the profile area and therefore the request. The create wizard's draft origin is no longer used by Home. A 409 `ADMINISTRATIVE_VERSION_CHANGED` shows the reselection copy and the "choose area" action instead of a generic failure.

## Validation

See the pull request for command output. Covered by `fresh-position.test.ts` (fresh last-known, stale then new fix, timeout, no permission/module/failure, stale new fix), `discovery-scope.spec.tsx` (precedence, reasons, pending account, account switch, foreground throttle and on-demand recheck) and `home-location-scope.spec.tsx` (waits for scope, GPS and area parameters and labels, no server scope, none-state actions for user and guest, replaced dataset).

Not run: device acceptance (permission granted/denied/revoked in Settings, return from background, poor GPS, account switch on hardware), DEV against a deployed #583.

## Rollback

Revert this PR; Home goes back to its previous unscoped/draft-origin request. Deploy GoGo-BE#583 first; an older backend ignores the area parameters and returns no `meta.location`, which Home already treats as "no label".
