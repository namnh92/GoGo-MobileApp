# APP-060 — most helpful three reviews and helpful marks

Refs #219. Stacked on APP-056 (#212, PR #241). Requires GoGo-BE#571 (PR #589, OpenAPI alpha.33, ADR-0026 proposal).

The Place Detail review section switches between "Mới nhất" and "Hữu ích nhất" (`order=latest|helpful`), with the selected chip marked by a check glyph and `accessibilityState.selected`. When the helpful order has no marks at all it says the latest reviews are shown. Each review shows its helpful count and a 44 pt toggle. Signed-in accounts mark and unmark it optimistically: count and toggle move on tap, a failure restores exactly the previous cache in both orders, a success applies the server's count, and both reads refetch. A tap on a review already in the requested state changes nothing, and a second tap while that review's request is in flight is dropped with the control disabled. A refused mark on one's own review explains itself; other failures ask to retry. Guests and signed-out readers see counts; tapping asks them to sign in, and sign-in returns to the place (`next=place:<uuid>`, validated). Hidden reviews disappear on the next server list. Both the preview and the caller's marks are excluded from offline persistence.
