# ADM-201 — shared administrative picker

Refs #148; also resolves the contract drift reported in #197 by vendoring BE develop OpenAPI alpha.29 and regenerating Mobile types.

The shared picker uses only public administrative APIs, with province → commune selection and optional whole-province scope. It stores canonical codes, datasetVersion and display-label snapshots. Changing province clears the commune; changing dataset requires reselection instead of silently remapping codes. Accent-insensitive local search covers the complete paginated list. Invalid hierarchy, repeated cursors and mixed-version pages are rejected. Successful versioned public snapshots participate in the existing offline query persistence.

Validation: generated contract check, typecheck and lint pass. 281 unit tests pass (39 skipped), including seven snapshot tests; three picker UI tests pass. Consumers are implemented in separate dependent tasks (#207/#208/#209/#214). This foundation alone does not claim those screens have migrated. DEV/device acceptance remains pending.

Rollback: revert consumers first, then this foundation. No new package or native dependency.
